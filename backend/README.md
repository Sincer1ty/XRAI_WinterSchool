# PC 프로그램 개발 위치

아직 실행 가능한 백엔드 코드는 없습니다. Python/FastAPI 구성을 제안한 단계입니다.

담당 범위: PPT 현재 페이지, 페이지별 입력·설정 저장, AI 대본 생성, 음성 인식·쉼 감지,
핵심 내용 전달 판단, 표시 타이머, 최소 복기 결과.

먼저 실제 Windows PowerPoint의 페이지 정보를 읽는 작은 검증부터 진행하고,
Android 담당자와 메시지·오디오 형식과 연결 복구 규칙을 합의합니다.
구현 시 의존성 파일과 실행 명령, `.env.example`을 함께 추가하세요. 실제 API 키는 넣지 않습니다.

자세한 범위는 [기능 문서](../docs/features.md), [구조](../docs/architecture.md), [분업](../docs/team-work.md)을 확인하세요.
