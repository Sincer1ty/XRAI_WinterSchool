# 분업 제안과 통합 확인

담당자는 아직 지정하지 않았습니다. 아래 역할은 2인 개발을 위한 제안입니다.

| 역할 | 주로 수정할 위치 | 첫 작업 |
|---|---|---|
| Android 담당 | `android/` | 한글 표시·갱신·숨김 확인, 입력한 힌트 전송, 숨김 중 음성 유지 검증 |
| PC·웹 담당 | `backend/`, `web/` | 페이지별 힌트 데이터, PPT 현재 페이지 읽기, 준비 화면과 PC 서버 시작 |
| 함께 | `docs/`와 통신 연결 부분 | 표시·숨김 요청, 음성 전달, 오류·재접속 상태의 형식 합의와 실기기 통합 |

## 구현 전 함께 정할 연결 규칙

실제 API나 확정 프로토콜이 아니라 합의해야 할 항목입니다.

- PC → 폰: 페이지 식별자, 제목·첫 구절, 표시·갱신·숨김 구분.
- 폰 → PC: 안경 연결 상태, 요청 성공·실패, 음성 데이터와 오디오 형식.
- 순서가 늦게 도착한 이전 페이지 요청을 구분할 방법.
- 재접속 후 현재 페이지·표시 상태를 복구하는 방법.
- 오류 상태와 힌트 타이머를 어느 쪽이 관리할지.

## 같이 확인할 시연

PPT 페이지 전환 → 현재 페이지 확인 → 설정한 시간 동안 쉼 → 해당 힌트 표시 → 핵심 내용 전달 인식 후 숨김 → 복기 확인.
전달 판단 실패 상황에서는 최대 표시 시간으로 숨기되, 전달 완료로 기록하지 않는지도 확인합니다.

Android와 PC 담당자가 같은 시리얼·경로·API 키를 소스에 넣지 않습니다.
통합 시간에는 실제 기기·마이크 권한·네트워크와 확인 결과를 함께 기록합니다.
