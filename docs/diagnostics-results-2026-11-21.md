## 첫 시험 당시 남은 확인

USB 디버깅 연결이 사라져 이후 화면 조작을 중단했다. 다음 항목은 아직 사용자 확인 필요다.

- 실제 안경 발화의 STT 변환과 폰 마이크 대체 여부.
- 기기 내 인식기·한국어 모델·외부 PCM 입력 지원.
- 힌트 표시·숨김의 실제 안경 반영.
- 숨김 후 음성 수신 유지와 새 문장 인식.
- 화면 회전·블루투스 재연결 동작.

USB 재연결 후 진단 화면 상태를 다시 읽고 이어서 확인한다. USB 연결 단절과 안경 블루투스 단절은 구분한다. 진단 화면을 나가거나 앱을 백그라운드로 보내면 음성·STT가 중지된다.
## USB 재연결 후 실기기 재시험

- USB 승인과 휴대폰 잠금 해제 후 별도 진단 앱으로 재진입했다.
- 기기 내 인식기 선택 상태를 확인했다.
- 별도의 직전 세션에서 확정 결과 '아 아 아'를 관찰했으나 입력 출처와 제시 문장 대조는 확인하지 못했다.
- 새 세션에서 인식기 준비 응답과 PCM 파이프 쓰기 증가를 확인했다.
- 입력 종료 시 파이프 쓰기 2,776,320바이트, 'STT 오류 7: 인식 결과 없음', 확정 결과 없음이 표시됐다.
- 사용자는 안내한 문장 시험에 대해 '인식이 안 되거나 오류가 보여요'라고 답했다. 문장 인식 성공으로 판정하지 않는다.
- 수신 계측 화면에서 7,076청크·4,528,640바이트·잘못된 청크 0·마지막 수신 후 0 ms·RMS 0.0001을 관찰했다. RMS는 단일 시점 값이며 발화 전체의 크기를 증명하지 않는다.
- 숨김 요청 뒤에는 7,258청크·4,645,120바이트·숨김 후 0바이트였지만, 이미 음성 수신 중지와 마지막 수신 후 91,965 ms가 표시돼 있었다. 숨김 때문에 수신이 중지됐다고 해석할 수 없다.
- 진단 화면과 연결 화면 사이의 상태 변화, 세션 재생성이 반복돼 숨김 중 수신 유지 시험은 조건을 통제하지 못했다. 같은 좌표 조작을 더 반복하지 않았다.

### 최신 판정 범위

- 빌드·단위 테스트 결과는 앞선 기록과 동일하다. 이번 재시험에서 소스 코드는 변경하지 않았다.
- 안경 오디오 수신과 STT 입력 파이프 전달: 계측값으로 확인.
- 제시 문장의 STT 인식: 확인되지 않음. 해당 세션은 ERROR_NO_MATCH로 종료.
- 실제 STT 입력 출처: 미확인.
- 실제 안경의 힌트 숨김과 숨김 중 음성 유지: 미확인.
- 인식기 지원 실패, 입력 음질·형식 문제, 실제 발화 수신 여부 중 어느 것이 원인인지 아직 확정할 수 없다.

### 다음에 확인할 순서

1. 휴대폰 조작과 원격 조작을 겹치지 않고 하나의 진단 화면을 유지한다.
2. 기존 음성 수신 화면에서 짧게 녹음·재생해 안경 음성이 실제로 들리는지 사용자가 확인한다.
3. 실제 PCM 형식과 음질을 확인한 뒤, 짧고 구분되는 문장으로 STT를 다시 시험한다.
4. 음성 수신이 증가하는 상태를 먼저 확인한 다음 숨김 전후 수신량을 비교한다.
5. 기기 내 인식기와 기본 인식기의 비교는 선택한 서비스의 외부 전송 여부를 확인하고 진행한다.
