# 구현할 기능

| 구분 | 구현할 기능 | 구체적인 동작 |
|---|---|---|
| **1. 발표 준비** | 페이지별 정보 입력 | 페이지 번호·제목·내용·전달 요점·필수 키워드를 입력합니다. 키워드는 페이지마다 최소 1개입니다. |
| **2. 대본 생성·확정** | AI 대본 초안 작성 | 입력한 정보를 바탕으로 초안을 만들고, 사용자가 수정해 최종 확정합니다. |
| **3. 연습·힌트 설정** | 회상 단서 편집 | 페이지마다 **제목 + 다음 설명의 첫 구절**을 정하고, 말을 멈춘 뒤 힌트가 뜨기까지의 대기 시간을 조정합니다. |
| **4. 실전 자동 표시** | PPT 연동·쉼 감지 | 현재 PPT 페이지를 파악하고, 설정한 시간 동안 말이 없으면 해당 페이지의 힌트를 표시합니다. |
| **5. 전달 판단·숨김** | 핵심 내용 전달 확인 | 발화를 분석해 필수 핵심 내용을 전달했다고 판단하면 **판단 시점부터 5초 이내**에 숨깁니다. 판단하지 못해도 최대 표시 시간이 지나면 숨깁니다. |
| **6. 발표 복기** | 결과 확인·단서 수정 | 페이지별로 **표시된 힌트와 핵심 내용 전달 여부**를 보여주고, 다음 발표에 쓸 단서를 수정합니다. |

## 범위와 완료 기준

- 준비·연습·복기는 웹 화면에서 진행하는 구성을 제안합니다.
- 힌트는 긴 대본 대신 페이지 제목과 다음 설명의 첫 구절로 구성합니다.
- 필수 핵심 내용은 키워드와 전달 요점을 함께 판단합니다. 단순 키워드 등장 여부만으로 축소하는 것은 아직 합의하지 않았습니다.
- 전달을 인식한 시점부터 5초 이내에 힌트를 숨깁니다.
- 전달을 인식하지 못해도 최대 표시 시간이 지나면 숨깁니다. 시간 초과를 전달 완료로 기록하지 않습니다.
- 복기는 페이지별 표시된 힌트와 필수 핵심 내용 전달 여부만 제공합니다. 인식 실패·미확인은 실제 미전달과 구분합니다.

## 개발 전 정할 정책

- 힌트 대기 시간의 기본값·범위·전체 또는 페이지별 적용.
- 최대 표시 시간과 같은 페이지에서 다시 표시할 조건.
- 여러 필수 요점, 의역·부정 표현·일부 설명의 전달 판단 기준.
- 페이지 전환·뒤로 이동·건너뛰기 시 이전 힌트와 타이머 처리.
- 연결 끊김, 마이크 입력 중단, AI 실패 시 상태와 복구 방식.
- 음성·텍스트의 외부 전송 동의, 저장 위치·기간·삭제 방식.

## 이번 범위에서 미룬 기능

PPT 내용 자동 추출, 음성 기반 페이지 추정, 상세 전사 타임라인, 자동 점수·숙달 판단, Q&A, 팀원 공유.
